# Presenze Marzo 2026

Questo repository contiene i file CSV con le presenze del personale per il mese di marzo 2026.

## File

- `matrice FILE ORE PRESENZA marzo 2026.csv` — Matrice delle ore di presenza per ciascun dipendente
- `tutti marzo 2026.csv` — Riepilogo completo delle presenze di marzo 2026

## Utilizzo

I file sono in formato CSV e possono essere aperti con Excel, LibreOffice Calc o qualsiasi editor di testo.
